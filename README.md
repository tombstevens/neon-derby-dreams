# Neon Derby Dreams

make a horse racing game, but the horses have to be 8 bit in 90s websafe colors, everything else should look like a curses ps1 game. you play as a down-on-their luck gambler who just found a $50 chip and converted it into 10x $5 chips, you need to gamble your way up to $5000
